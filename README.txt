Kostenlos online stellen (empfohlen): GitHub Pages oder Cloudflare Pages.

GitHub Pages Kurzweg:
1. Neues öffentliches Repository erstellen, z. B. recall-website.
2. Alle Dateien aus diesem Ordner in die oberste Ebene des Repositories laden.
3. Repository > Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, Folder: /(root), Save.
6. Nach kurzer Zeit erscheint die kostenlose https://<username>.github.io/recall-website/ Adresse.

Vor kommerzieller Veröffentlichung:
- TODOs in privacy.html und imprint.html ausfüllen/rechtlich prüfen.
- Support-E-Mail in support.html ergänzen.
- APK-Link später in index.html statt "Android APK · bald" setzen.
